Selected-file writes use bounded buffers and the same codec size policy. Index reads use the existing bounded header/seek reader. An absent record may retain legacy tags; explicit embedded[] overrides all fallback. Unsupported/malformed/change-during-read are distinct from known empty. ADD rereads current tags under the caller's mutation lock; REPLACE can require the supplied revision. Stage buffers, exact recovery bytes, permissions and mtime belong to each transaction. Rollback restores only a still-matching own result; a newer external file is preserved and reported. Source+legacy retirement are authoritative; generated indexes remain derived. No HTTP paths, capabilities, cloud proxy or global lock policy are changed in this stage.
