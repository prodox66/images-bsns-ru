# Правила репозитория images.bsns.ru

- Репозиторий содержит статический интерфейс и генератор публичной библиотеки изображений.
- Реальные изображения и generated index/data размещаются в `images/`, передаются через FTP и не входят в Git.
- Все URL, имена global-контрактов и размер страницы задаются в `runtime-config.js` либо в конфигурационном объекте генератора.
- Runtime остаётся статическим: PHP и база данных не используются.
- Перед публикацией обязательны contract-тест и три чистых browser-цикла.
- Не добавлять секреты, токены и пользовательские файлы.
